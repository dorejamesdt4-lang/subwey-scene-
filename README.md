# Nightmare Frequency — Godot subway plates

Godot 4.4.1 project: fixed illustrated backgrounds, a 3D walking player, invisible collision / navigation geometry, foreground cutouts, screen-confined glitch rain, mist and flickering light overlays. No browser runtime.

## Run

Clone this repository, import `project.godot` in Godot 4.4 or newer, wait for artwork imports, and press F6 on `scenes/main.tscn` or F5 to run the project.

| Action | Keyboard / mouse | Controller |
|---|---|---|
| Move | WASD or arrow keys | Left stick |
| Optional click movement | Left-click inside floor | — |
| Open nearby normal door | E | South face button (Xbox A) |
| Area map | M | Back / Select |
| Close map | Esc | East face button (Xbox B) |
| Atmosphere toggle | F | — |

## Player model

The included articulated 3D test rig verifies walking and perspective; it is not approved character artwork. Import your rigged GLB, create its model scene, and assign it to **Player Model** on the main scene's root. The player controller keeps collision and navigation independent of the model. AnimationTree / combat / crafting are future integration work; their input actions are reserved, not implemented.

## Plate construction

`data/rooms.json` defines each floor footprint, doorway, screen polygon and room connection in normalized artwork coordinates. Invisible 3D floors and boundary walls are generated by projecting those polygons onto the ground through the camera. Navigation triangulation uses the same floor geometry. Exact artwork foreground pixels are cut into transparent overlays; original plate files are preserved independently.

All nine room views are linked in both directions. Normal rectangular hinged doors are used by default. The four supplied special door sheets are reference-only and are never selected at runtime.

Hallway depth zones switch between the original view and a matched camera/plate crop with hysteresis. These are crops of one perspective, not invented alternate views. Truly different camera angles require additional painted plates and corresponding calibrated cameras; the current images cannot supply unseen room geometry.

## Editing and limitations

Floor / screen / foreground boundaries are initial calibration and need visual review with the final character. Foreground layers cover near pillars or furniture; they are not a complete per-pixel depth reconstruction. Door placement is an editable initial layout. Animated mist and illumination are independent Godot shaders. Rain is clipped to the configured screen faces. Lighting and movement need a Windows/controller playtest before being treated as approved.

See `docs/HANDOVER.md` and the smoke test for validation status.
